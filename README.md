# Track — My Progress: Daily Productivity & Progress Tracker

A modern, responsive personal productivity web application built with React, TypeScript, Tailwind CSS, and Recharts.

## Features
- **Daily Overview**: Track total tasks, completed, pending, and completion percentage with animated counters.
- **Task Management**: Full task tracking with categories (Coding/DSA, Projects, Learning, College, Fitness, Personal, Others), priorities, and filters.
- **Interactive Analytics**: Daily Donut Chart, Category Bar Graph, 7-Day Consistency Trend, and Monthly Summary.
- **Complete My Day**: Dedicated day closure feature with honest completion tracking.
- **High-Res PNG Export**: Generate beautiful achievement reports formatted for WhatsApp Status and Instagram.
- **Interactive Calendar**: History review, completion badges, and streak calculation.
- **Local Persistence**: Full data persistence with export/import backup and Dark/Light themes.
